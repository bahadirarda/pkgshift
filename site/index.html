01 / Why pkgshift

A lockfile is only the visible part.

Package manager behavior reaches across the repository. A useful migration tool has to understand the whole system, not replace one file and hope for the best.

A

Repository understanding

Manifests, workspaces, catalogs, overrides, patches, registries, CI, containers, and contributor commands become evidence in one normalized Project IR.

package.jsonpnpm-workspace.yaml.npmrcDockerfileci.yml
B

Fail closed

Unsupported semantics and source-to-target resolution drift block execution instead of hiding uncertainty behind a successful installer exit.

C

Recoverable by design

Integrity-checked snapshots and a run journal exist before the first repository write.

rollback

02 / Transaction model

One command.
Five explicit stages.

The guided command keeps a strict boundary between understanding, isolated execution proof, and changing the repository.

  1. 01

    Inspect

    Detect the source package manager and collect repository evidence without writing state.

    read-only
  2. 02

    Plan

    Evaluate target capabilities and produce immutable operations with exact before-and-after digests.

    read-only
  3. 03

    Approve

    Cross the mutation boundary only after a person approves the exact plan identifier.

    boundary
  4. 04

    Apply

    Recheck preconditions, snapshot affected files, and execute the approved operations transactionally.

    write
  5. 05

    Verify

    Compare normalized lock graphs and confirm target selection, workspace membership, file digests, and installer completion.

    read-only

03 / Agent-ready

Your agent operates the tool. It does not invent the migration.

pkgshift is built for coding agents and humans from the same deterministic core. JSON output, stable exit codes, and exact next actions make the approval contract machine-readable.

pkgshift to bun --trial runs the accepted importer, installer, and graph verification in a disposable copy before any repository-write approval.

05 / Install

Start with one command.

The installer detects Linux or macOS, downloads the matching native archive, verifies its SHA-256 checksum, and installs into your user bin directory by default.

Shell Manual download
curl --proto '=https' --tlsv1.2 -LsSf https://bahadirarda.github.io/pkgshift/install.sh | sh

Pin a release with PKGSHIFT_VERSION=v0.1.0. Review the installer source before running it.

Then, from a project root: pkgshift to bun --dry-run
