# Architecture Decisions

* [Agent-first CLI](agent-first-cli.md) - Makes structured, noninteractive behavior a primary interface.
* [Transactional Migrations](transactional-migrations.md) - Separates planning from mutation and journals every run.
* [Shared Agent Skills Path](shared-agent-skills-path.md) - Preserves one portable source across Codex and Claude Code discovery roots.
* [Rust-Primary Polyglot Monorepo](rust-primary-polyglot-monorepo.md) - Keeps Rust and the TypeScript parity reference in one governed product repository.
